## 简介

这是为《The Complex》后室短片项目制作的A类全封闭防化服角色模型。
包含建模、贴图、骨骼绑定和权重，适用于 Blender，可导出至 Unity / VRChat 等平台。

我没找到 B 站有免费开源、且带完整 Humanoid 绑定和说明的同类防化服模型，所以自己从零做了一个。
除 ASYNC Logo 外，模型和贴图均为原创。
